# PJCDb Decryptor

## 项目概述

PJCDb Decryptor 是一个旨在演示和研究 Microsoft Office 文档（特别是 PowerPoint 和 Excel 文件）加密机制的工具。本项目基于早期发现的漏洞，通过模拟 Office 应用程序的行为，尝试在加密流程中寻找可利用的时间窗口，从而实现对受保护文档的“解密”或绕过密码保护。请注意，此工具的有效性可能受 Office 版本更新和安全补丁的影响，因此其功能可能已不再适用。

## 特性

- **自动化文档处理**：自动扫描指定目录下的 PowerPoint 文件。
- **模拟解密流程**：通过 COM 接口与 Office 应用程序交互，模拟打开和另存为操作。
- **文件类型转换**：将受保护的 `.pptx` 或 `.ppt` 文件另存为 `.ini` 格式，随后重命名以移除加密属性。
- **错误处理机制**：内置异常捕获，以应对文件损坏或权限问题。

## 使用方法

1.  **环境准备**：
    *   确保您的系统已安装 Microsoft Office 应用程序。
    *   安装 `pywin32` 库：`pip install pywin32`。

2.  **运行脚本**：
    *   将 `pjcdb_decryptor.py` 脚本放置在包含待解密 Office 文件的目录中。
    *   执行脚本：`python pjcdb_decryptor.py`。

3.  **结果查看**：
    *   解密后的文件将保存在当前目录下的 `test` 文件夹中。
